# UIL-per
A website made to help students prepare for Texas's UIL Number Sense and General Math competitions by providing practice questions of the type they expect to see in their tests.

**How to Preview on your Local Machine**
1. git clone the repository.
2. Run `cd UIL-per/my-react-app`
3. Run `npm install`. This will install all necessary packages for the website to run.
4. Run `npm run dev`.
5. You can see the website by typing in _http://localhost:5173/_ into your browser!
